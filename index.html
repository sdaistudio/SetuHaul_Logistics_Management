Drivers report delays on WhatsApp in any of seven languages: English, Hinglish, Hindi, Gujarati, Marathi, Punjabi or Marwari. SetuHaul reads the words, checks every dock door against the rules, offers only slots that really work, and books the one they pick in a single checked transaction. Hard cases go to a coordinator with everything on one screen.

Who owns each decision

Language at the edges, deterministic code in the middle. Nothing in the path lets a model choose a slot.

01 · WORDS

The model reads

Rules first; an LLM only when rules return UNKNOWN, with a strict JSON schema. It can change what we ask, never what we book.

02 · CAPACITY

Code decides

A 15-point feasibility check per slot, earmarks for scarce capacity, and a planner that only proposes.

03 · RECORD

The database refuses

One write lock, an overlap trigger and partial unique indexes. Conflicting writes cannot land.

04 · PEOPLE

A person decides

Safety, penalties, no-slot cases and data conflicts go to the right person by a channel that works.
